
# Student Freelance & Gig Exchange

A **campus-specific freelance marketplace** developed as part of the **CSE470** course. The platform connects students who want to offer services—such as tutoring, graphic design, programming, and other academic or creative work—with fellow students looking to hire them.

## Project Overview

The system provides a complete workflow for managing freelance gigs within a university environment. Sellers can create and manage service listings, showcase their portfolios, handle hire requests, track active orders, deliver completed work, and monitor their earnings. Buyers can browse and search available gigs, submit hire requests, manage ongoing orders, request revisions, leave reviews and ratings, and save interesting gigs for future reference.

## Key Features

* **Seller Management**

  * Create, edit, archive, and manage gig listings
  * Upload portfolio items
  * Manage hire requests and active orders
  * Submit final deliverables
  * View earnings and completed work through a seller dashboard

* **Marketplace & Discovery**

  * Browse all active gigs
  * Filter by category
  * Sort by price
  * Search using keywords
  * View seller profiles, ratings, and reviews

* **Order Workflow**

  * Submit and manage hire requests
  * Accept or decline requests
  * Track order progress through multiple status stages
  * Deliver completed work and request revisions when needed

* **Reviews & Ratings**

  * Leave written reviews
  * Rate completed services using a 1–5 star system
  * Build seller reputation through public feedback

## Non-Functional Requirements

The platform is designed with a focus on:

* **Performance:** Fast browsing, searching, and filtering.
* **Scalability:** Support for increasing users, gigs, and orders.
* **Security:** Secure authentication, HTTPS, authorization, and validated file uploads.
* **Usability:** Responsive, intuitive interface for both desktop and mobile devices.
* **Reliability:** Consistent order processing and transactional integrity.
* **Maintainability:** Modular architecture with clear separation of presentation, business logic, and data layers.
* **Data Integrity:** Reviews only after completed orders and maintained order history.
* **Compatibility:** Support for modern web browsers.
* **Privacy:** User account and data deletion support.
